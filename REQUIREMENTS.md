# Orbpad System Requirements

## Orbpad v1.0.0

Orbpad v1.0.0 is currently released for Windows x64.

---

## Supported Operating Systems

- Windows 10
- Windows 11

### Architecture

- x64

---

## Runtime

The official Orbpad v1.0.0 release is distributed as a **self-contained .NET application**.

A separate .NET runtime installation is not required for the standard Orbpad installer.

Orbpad v1.0.0 is built with .NET 10.

---

## Hardware Requirements

### Minimum

- 64-bit x64 processor
- 4 GB RAM
- Approximately 200 MB of available storage

### Recommended

- 64-bit multi-core processor
- 8 GB RAM or more
- SSD storage
- 1280 × 720 display resolution or higher

Actual memory usage depends on document size, number of open documents, images, and other content.

---

## Internet Connection

An internet connection is **not required for normal text editing**.

Internet access may be required for features or content that rely on external web resources.

---

## File Access

Orbpad reads and writes files using the permissions available to the current Windows user.

You must have appropriate permissions to access files and folders you want to edit.

---

## Installation Permissions

The Orbpad installer may request administrator privileges when installing Orbpad into the standard Windows program directory.

The installed application does not normally require administrator privileges for everyday editing.

---

## Supported File Types

Orbpad is designed primarily for:

- Plain-text files
- Markdown files
- Source-code files supported by the available syntax-highlighting grammars
- Supported image files
